# Aurora

A **premium, animated restaurant demo website** built with **raw HTML, CSS, and JavaScript**. This project showcases smooth scroll-based animations, dynamic text effects, and image placeholders for a cinematic, food-focused experience. The website is designed as a modern, elegant landing page for restaurants, featuring smooth animations and interactive elements.

### Key Features:
- **Premium Design**: Elegant layout with a warm, cinematic feel.
- **Smooth Animations**: Scroll-triggered animations and dynamic text effects.
- **Image Placeholders**: Placeholder spaces for images that can be added locally.
- **Responsive**: Optimized for mobile-first design, ensuring a great experience on all devices.
- **Interactive Elements**: Hover effects on buttons, cards, and images for enhanced user experience.

### Sections Included:
1. **Hero Section**: Full-screen intro with restaurant name, tagline, and a call-to-action button.
2. **About Section**: Two-column layout with restaurant info and an image placeholder.
3. **Signature Dishes Section**: Grid layout showcasing featured dishes with hover animations.
4. **Text-Focused Story Section**: Emphasizing the restaurant's philosophy with text animation.
5. **Reservation CTA**: Call-to-action for making a reservation with a prominent button.
6. **Footer**: Minimal footer with restaurant details and social links.

### Technologies Used:
- **HTML**: Markup for structuring the content.
- **CSS**: Styling with animations, transitions, and responsive design.
- **JavaScript**: Used for scroll-based animations and dynamic text effects.

### Demo:
You can preview the website by simply opening the `index.html` file in your browser. The website is ready for you to integrate images locally.
